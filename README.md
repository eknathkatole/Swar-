# Swar Swami Gurukul — Website Starter

A responsive one-page static website inspired by the *editorial structure* of modern spiritual/education websites, while using original Swar Swami Gurukul content and branding.

## Run
1. Open `index.html` directly in Chrome, or
2. Use VS Code + Live Server.

## Main files
- `index.html` — complete webpage
- `assets/` — supplied/reference images and cropped hero assets

## Replace later
- `assets/swami-samarth.jpg` with a clean transparent PNG of Swami Samarth
- `assets/pt-sanjay-patki.jpg` with a high-resolution transparent PNG/photo of Pt. Sanjay Patki
- Event dates/text
- Phone number if required
- YouTube/Instagram links if they change

## Design direction
Deep navy + saffron + ivory, editorial typography, devotional mantra details, minimal layouts, and large visual sections.
